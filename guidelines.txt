Date: January 2, 2026
Issue: npm run dev failed with "Cannot find module '../lightningcss.win32-x64-msvc.node'"

Error Details:
  - lightningcss native binary for Windows x64 MSVC was not installed correctly
  - Tailwind CSS v4 has hard dependency on lightningcss for CSS processing
  - PostCSS configuration was trying to load @tailwindcss/postcss plugin
  - globals.css was importing tailwindcss which triggered the module resolution
